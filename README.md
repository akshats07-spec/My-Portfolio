# Akshat Jain Portfolio

Responsive portfolio built with HTML, CSS and JavaScript.

## Preview
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a repository named `akshats07-spec.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open Settings → Pages.
4. Select Deploy from a branch, choose `main` and `/ (root)`, then save.
5. After deployment, the website should be available at `https://akshats07-spec.github.io/`.

Please verify all project descriptions and add project dates, repository/demo links and expected graduation year before publishing.
